# Chapter 6. 인체 GEM과 맥락 특이 모델

> [Chapter 5](../chapter-5/README.md)는 반응 근거를 모아 재구축하고 구조·기능을 검증하는 원칙을 다뤘다. 이 장은 그 원칙을 인체 GEM의 계보와 공개 큐레이션에 적용한 뒤, 범용 인체 재구축을 조직·세포·조건별 모델로 좁히는 선택과 검증을 연결한다.

## 표기와 읽기 원칙

이 장은 한국어 용어를 먼저 쓰고 처음 등장할 때 영어 원어와 약어를 병기한다. 이후에는 같은 표기를 일관되게 사용한다.

- **범용 인체 재구축(generic human reconstruction)**은 여러 인간 세포 유형에서 지지된 반응의 통합 지식 기반이다.
- **[맥락 특이 모델(context-specific model)](../glossary.md)**은 특정 조직·세포·질병 상태의 자료와 기능 요구를 반영한 계산 모델이다.
- **재구축(reconstruction)**, 계산용 **model**, 저장소 **release/tag**와 파생 모델을 구분한다.
- **반응 활성 점수(reaction activity score, RAS)**는 GPR과 발현값을 연결한 증거 점수이지 flux의 직접 측정값이 아니다.
- **배지·경계조건·목적함수·대사 과제·solver**는 생물학적 사실이 아니라 분석자가 명시하는 계산 조건이다.

{% hint style="warning" %}
본문의 “예측”은 명시된 모델 릴리스·오믹스 자료·배지·경계조건·목적함수 또는 대사 과제 아래의 계산 결과이다. 실험 관찰이나 인과적 효과와 혼용하지 않는다.
{% endhint %}

## 이 장을 시작하며

인체 모델링에는 두 개의 서로 다른 선택 문제가 연속해서 나타난다. 먼저 여러 재구축과 문헌 근거에서 인간 대사 반응의 범용 지식 기반을 정리해야 한다. 다음으로 범용 모델에서 특정 조직·세포주·질병 조건에 필요한 반응과 기능을 골라야 한다. 첫 번째 선택은 식별자·반응식·구획·GPR 큐레이션의 문제이고, 두 번째 선택은 오믹스 증거·배지·대사 과제·검증 endpoint의 문제이다.

3. [Human1·Human2 통합과 큐레이션](03.md)

수식은 반응 선택의 생물학적 의미를 설명하는 데 필요한 범위에서만 사용한다. 핵심은 어떤 반응을 어떤 증거로 남기고 어떤 기능·외부 자료로 검증하는가이다.

## 이 장을 읽는 방법

각 절의 숫자와 결과를 다음 세 질문으로 읽는다.

1. **객체:** 범용 재구축, 계산 model, 맥락 특이 모델과 파생 모델 가운데 무엇을 평가했는가?
2. **선택:** 반응을 남기거나 제약한 근거가 문헌, GPR, 오믹스, 배지와 대사 과제 가운데 무엇인가?
3. **검증:** 내부 구조·대사 과제 검사와 구축에 쓰지 않은 외부 자료 검증을 구분했는가?

인체 GEM의 반응·대사물·유전자 수는 모델 릴리스와 집계 정의의 속성이다. 알고리즘별 모델 크기도 입력 자료와 설정의 결과이다. 두 종류의 숫자를 생물학적 품질 순위로 읽지 않는다.

{% hint style="warning" %}
발현 임계값과 오믹스 통합법은 보편 상수가 아니다. 기저 모델, 배지, 대사 과제와 임계값을 바꾼 민감도 분석을 수행하고 실패한 표본과 infeasible 결과도 함께 보고한다.
{% endhint %}

## 학습 목표

이 장을 마치면 다음을 수행한다.

1. 범용 인체 재구축과 맥락 특이 모델의 적용 범위를 정의하고 검증 endpoint를 구분한다.
2. Recon·HMR·Human-GEM 계보를 설명하고, 릴리스·집계 기준이 다른 모델 규모를 비교한다.
3. Human1의 통합 큐레이션과 Human2의 LLM 보조 후보 선별·전문가 판정을 구분한다.
4. 오믹스 증거가 반응 선택·벌점·bounds로 변환되는 파이프라인을 추적한다.
5. INIT·tINIT·ftINIT의 반응 선택과 대사 과제 보존 절차를 비교한다.
6. GPR의 AND·OR에서 RAS를 계산하고 결측·임계값의 영향을 평가한다.
7. GIMME·iMAT·E-Flux·tINIT의 생물학적 질문, 계산 형식과 결과 의미를 비교한다.
8. raw counts·FPKM·TPM과 벌크·단일세포 RNA-seq의 전처리 차이를 설명한다.
9. 다중 오믹스의 충돌·결측·시간 불일치를 분류하고 독립 검증 전략을 설계한다.

실습은 RNA-seq에서 RAS를 계산하고 GIMME·E-Flux 제약을 적용하는 과정을 `e_coli_core`로 재현한다. 인체 세포주의 계산·실험 유전자 의존성 비교는 [Chapter 9 §3](../chapter-9/03.md), 미생물 교란 방법의 선택은 [Chapter 4 §13](../chapter-4/13.md), 생산–성장 포락선 실습은 [Chapter 10 §11](../chapter-10/11.md)으로 이어진다.
