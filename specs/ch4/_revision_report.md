## 삭제·축약 근거

- 02.md의 경사하강법 비교, 일반형-표준형 변환, 슬랙 변수와 목적함수 기울기 전개를 삭제했다. 선형대수·최적화 미수강 독자에게 직접 필요한 입력·배지·반응 방향으로 대체했다.
- 꼭짓점 정리와 증명, 조합론적 상한, 심플렉스 타블로, 내점법 유도와 KKT 전개를 삭제했다. 04.md는 솔버 상태와 결과 검산 절차로 재구성했다.
- 05.md의 쌍대 문제, 그림자 가격, 환원비용, 쌍대 유도와 기저 역행렬 계산을 전부 삭제했다. GPR 논리, 반응 결손, 단일 유전자 결손과 조건 특이적 필수성의 생물학적 입문으로 다시 썼다.
- 고급 기하와 알고리즘 증명 대신 FBA의 최소 수식 하나, 교환 반응 부호, 배지 통제, 결과 provenance와 해석 한계를 남겼다.
- 기존 Chapter 8과 보충자료의 설명을 복사하지 않고, Chapter 4의 “기준 설정 → 결손 → 상태 선택” 흐름에 맞추어 11.md MOMA, 12.md ROOM, 13.md 방법 비교를 새로 구성했다. MOMA·ROOM 수식은 질문, 추가 입력, 핵심 가정과 출력 오독 방지에 필요한 수준으로 제한했다.

## 시각화 설계

- 번호 절별 기존 Markdown 이미지·Mermaid를 먼저 세고 부족분만 보충하여, 기존 시각화 6개와 신규 JSON spec 20개로 절당 두 개·총 26개의 최종 그림 계획을 구성했다.
- 모든 spec은 `name`, `out_dir`, `aspect`, `size`, `prompt` 키를 사용하며 `size`는 `2K`, 출력 디렉터리는 `figures/ch4`로 통일했다.
- 각 prompt는 `final_prompt_info.md`의 STYLE 전치를 전제로 정확한 한글 라벨, 의미별 색 역할, 캡션·로고·워터마크 금지와 교육용 모식도 범위를 명시했다.
- `_placement.md`에는 절별 기존·신규 수량과 최종 합계, 두 삽입 위치와 그림 4.1~4.26의 자립 캡션 초안을 기록했다.
- API key가 없으므로 신규 이미지 생성·검수, 신규 본문 이미지 링크 삽입과 자산 등록은 수행하지 않았다.
