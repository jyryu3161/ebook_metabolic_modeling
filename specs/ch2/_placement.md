# Chapter 2 신규 그림 배치안

이 문서는 Nano Banana Pro용 신규 그림 8개의 삽입 위치와 자립 캡션을 기록한다. 8개 이미지는 원본 해상도에서 과학·한글·상세도 검수를 통과했으며, PASS 결과만 본문과 `.gitbook/assets/nano/ch2/`에 반영했다. 상세 판정 근거는 `figures/ch2/_QA_REPORT.md`에 기록했다.

본문의 `그림 2.1`과 `그림 2.2`는 유지했다. 기존 `chapter-2/03.md`의 Mermaid는 `그림 2.7`로 바꾸고, 신규 그림을 아래 순서대로 배치해 장 전체 번호를 `그림 2.1`부터 `그림 2.11`까지 연속으로 정리했다.

### `fig03.json` — 계획 번호 그림 2.3

- 대체 텍스트 초안: 중앙 반응식과 반응 ID·화학량론·플럭스 범위·유전자 규칙·구획·주석 필드의 연결 구조.
- 자립 캡션 초안: _그림 2.3:_ 반응 기록은 반응 ID, 순 화학량론 계수, 플럭스 하한·상한, GPR, 구획과 데이터베이스 주석을 구분해 저장한다. 중앙의 $$A+2B\rightarrow3C$$는 교육용 반응식이며, 계수는 몰비이고 플럭스 범위는 허용 조건일 뿐 실제 반응속도 측정값이 아니다. 특정 모델 계산 결과가 아닌 교육용 모식도이다. 저자 작성; 개념 근거: [Orth, Thiele, Palsson (2010)](https://doi.org/10.1038/nbt.1614).

### `fig04.json` — 계획 번호 그림 2.4

- 삽입 위치: §1.2의 bound 설정 표 뒤.
- 목적: 저장된 반응식의 방향, 플럭스 부호와 허용 구간을 분리해 읽게 한다.
- 대체 텍스트 초안: 저장 반응 A에서 B 방향을 기준으로 정방향·양방향·정지 플럭스 범위를 비교한 세 패널.
- 자립 캡션 초안: _그림 2.4:_ 저장 반응식 $$A\rightarrow B$$를 기준으로 양의 플럭스는 저장된 정방향, 음의 플럭스는 역방향 진행을 나타낸다. 패널 A는 $$0\leq v\leq10$$, 패널 B는 $$-10\leq v\leq10$$, 패널 C는 $$v=0$$인 계산 조건을 비교한다. 플럭스 부호와 bounds는 모델의 저장 규약이며 실제 세포 조건의 열역학적 방향성을 단독으로 증명하지 않는다. 특정 모델 계산 결과가 아닌 교육용 모식도이다. 저자 작성; 개념 근거: [Orth, Thiele, Palsson (2010)](https://doi.org/10.1038/nbt.1614).

## `chapter-2/02.md`

### `fig05.json` — 계획 번호 그림 2.5

- 삽입 위치: 예제 2.1의 헥소키나제 비영 계수 표 뒤.
- 목적: 반응물의 음수 계수와 생성물의 양수 계수가 행렬의 한 열로 옮겨지는 과정을 보여 준다.
- 대체 텍스트 초안: ATP와 포도당이 ADP·G6P·양성자로 바뀌는 반응식과 대응하는 화학량론 행렬 열.
- 자립 캡션 초안: _그림 2.5:_ 교육용 헥소키나제 반응식의 반응물 ATP와 포도당은 $$-1$$, 생성물 ADP·G6P·$$\mathrm{H^+}$$는 $$+1$$로 한 반응 열에 기록된다. 부호는 저장된 반응식에서의 소비와 생성을 나타내며, 계수는 반응속도가 아니라 무차원 몰비이다. 특정 모델의 플럭스 계산 결과가 아닌 화학량론 변환 모식도이다. 저자 작성; 개념 근거: [Orth, Fleming, Palsson (2010)](https://pubmed.ncbi.nlm.nih.gov/26443778/).

### `fig06.json` — 계획 번호 그림 2.6

- 삽입 위치: §2.3의 장난감 화학량론 행렬과 행·열 순서 설명 뒤.
- 목적: 열은 반응 기록, 행은 한 대사물의 생성·소비 합계라는 두 읽기 방향을 함께 제시한다.
- 대체 텍스트 초안: 세 대사물과 세 반응의 화학량론 행렬에서 R2 열과 B 행을 각각 강조한 물질수지 기록표.
- 자립 캡션 초안: _그림 2.6:_ 장난감 네트워크의 화학량론 행렬에서 열 $$R_2$$는 반응 $$B\rightarrow C$$의 계수를 기록하고, 행 $$B$$는 모든 반응이 대사물 $$B$$의 순생성률에 기여하는 값을 모은다. 강조한 식은 $$B$$ 행의 각 계수에 같은 열의 플럭스를 곱해 더하는 과정을 나타낸다. 특정 모델 계산 결과가 아닌 교육용 행렬 모식도이다. 저자 작성; 개념 근거: [Orth, Thiele, Palsson (2010)](https://doi.org/10.1038/nbt.1614).

### `fig08.json` — 계획 번호 그림 2.8

- 삽입 위치: §3.3에서 $$A+2B\rightarrow C+D$$의 두 투영 규칙 표 뒤.
- 목적: 반응 노드를 제거하는 투영에서 계수와 다자 관계가 사라짐을 시각적으로 비교한다.
- 대체 텍스트 초안: 반응 노드를 유지한 A+2B에서 C+D 이분 그래프와 반응 노드를 제거한 대사물 투영 그래프의 비교.
- 자립 캡션 초안: _그림 2.8:_ 패널 A의 부호·가중 이분 그래프는 반응 노드 $$R_1$$과 화학량론 가중치 2를 보존한다. 패널 B의 기질–생성물 투영은 $$A\rightarrow C$$, $$A\rightarrow D$$, $$B\rightarrow C$$, $$B\rightarrow D$$ 연결만 남기므로 계수 2와 네 대사물이 한 반응에 함께 참여한다는 관계를 잃는다. 특정 모델 계산 결과가 아닌 교육용 그래프 모식도이다. 저자 작성; 개념 근거: [Samal and Martin (2011)](https://doi.org/10.1371/journal.pone.0022295).

### `fig09.json` — 계획 번호 그림 2.9

- 삽입 위치: 반례 3.1의 마지막 문단 뒤.
- 목적: 그래프 경로의 존재와 물질수지·bounds를 만족하는 비영 플럭스의 존재를 구분한다.
- 대체 텍스트 초안: A에서 B를 거쳐 C로 이어지는 그래프 경로와 R2가 0으로 고정되어 R1도 0이 되는 물질수지 비교.
- 자립 캡션 초안: _그림 2.9:_ 패널 A에서는 $$A_e\rightarrow B_c\rightarrow C_e$$의 연결 경로가 존재한다. 패널 B에서 $$v_2=0$$을 부과하면 내부 대사물 $$B_c$$의 물질수지 $$v_1-v_2=0$$에 따라 $$v_1=0$$이므로, 같은 경로에 비영 정상상태 플럭스가 흐를 수 없다. 이는 특정 GEM 계산이 아니라 경로와 물질수지의 차이를 보이는 교육용 반례이다. 저자 작성; 개념 근거: [Orth, Thiele, Palsson (2010)](https://doi.org/10.1038/nbt.1614).

### `fig10.json` — 계획 번호 그림 2.10

- 삽입 위치: §4.1의 $$(\mathbf{S}\mathbf{v})_i=\text{총생성률}-\text{총소비률}$$ 식 뒤.
- 목적: $$\mathbf{S}\mathbf{v}=0$$을 대사물별 유입·유출이 맞는 상태로 직관화한다.
- 대체 텍스트 초안: 대사물 B 풀에 생성 기여 4와 2가 들어오고 소비 기여 6이 나가 순생성률이 0인 물질수지.
- 자립 캡션 초안: _그림 2.10:_ 대사물 $$B$$에 대한 두 생성 기여가 $$4+2=6$$이고 소비 기여가 6이면 순생성률은 0이다. 아래 비교에서는 생성 6과 소비 5가 맞지 않아 순생성률이 $$+1$$이며, 이 플럭스 조합을 지속하면 $$B$$가 축적된다. 단위를 지정하지 않은 교육용 물질수지 모식도이며 실제 모델 계산 결과가 아니다. 저자 작성; 개념 근거: [Orth, Thiele, Palsson (2010)](https://doi.org/10.1038/nbt.1614).

## 생성 후 필수 검수

1. 각 JSON을 `gen_one.py`에 한 개씩 입력하고 2K 결과를 생성한다.
2. 과학 검수에서 반응 방향, 계수, bounds, 행별 합과 화살표 대상을 확인한다.
3. 한글을 음절 단위로 읽어 오타·깨짐·환각 텍스트가 없는지 확인한다.
4. 패널, 계수와 핵심 라벨이 spec에서 빠지지 않았는지 원본 대비 상세도를 확인한다.
5. 검수를 통과한 뒤에만 본문 링크, 최종 캡션, 그림 번호와 권리 장부를 함께 갱신한다.
