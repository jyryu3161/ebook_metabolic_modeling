## `chapter-1/03.md`

### `fig06.json` — 계획 번호 그림 1.6

- 삽입 위치: §3.1에서 “두 열의 결과를 비교할 때에는 재구축 자체가 달라진 것이 아니라 조건과 목적이 달라졌음을 함께 기록한다” 문단 바로 뒤.
- 목적: 하나의 재구축에 서로 다른 배지·경계·목적을 붙이면 별도의 조건부 계산 모델과 예측이 된다는 구분을 보여 준다.
- 대체 텍스트 초안: 반응·대사물·GPR·구획·근거를 담은 공유 재구축에서 포도당 성장 조건과 아세테이트 ATP 유지 조건의 두 계산 모델이 갈라지는 구조.
- 자립 캡션 초안: _그림 1.6:_ 하나의 재구축은 반응·대사물·GPR·구획과 근거를 공유하지만, 포도당 배지에서 성장을 목적으로 둔 모델과 아세테이트 배지에서 ATP 유지를 평가하는 모델은 서로 다른 조건부 계산 문제이다. 가지는 재구축의 생화학 지식이 바뀐다는 뜻이 아니라 배지·경계·목적이 달라짐을 나타낸다. solver나 실제 GEM 계산을 사용하지 않은 교육용 개념 모식도이다. 저자 작성; 개념 근거: [Thiele and Palsson (2010)](https://doi.org/10.1038/nprot.2009.203), [Orth, Thiele and Palsson (2010)](https://doi.org/10.1038/nbt.1614).

- 삽입 위치: §4.3의 제약 기반 모델·동역학 모델 비교 표와 이어지는 방법 선택 문단 뒤, §4.4 제목 바로 앞.

- 대체 텍스트 초안: 화학량론·경계·배지·목적에서 여러 가능한 플럭스 경로로 이어지는 제약 기반 패널과 초기 농도·속도식·매개변수에서 시간별 농도 곡선으로 이어지는 동역학 패널.
- 자립 캡션 초안: _그림 1.8:_ 제약 기반 모델은 화학량론·반응 경계·배지와 목적을 만족하는 플럭스 상태의 범위를 비교하고, 동역학 모델은 초기 농도·속도식·매개변수에서 출발해 농도의 시간 변화를 계산한다. 왼쪽의 여러 경로는 실제 세포가 동시에 취한 상태나 시간 순서를 뜻하지 않으며, 오른쪽 곡선은 수치 자료가 아닌 개념 표현이다. solver나 실제 GEM 계산을 사용하지 않은 교육용 비교 모식도이다. 저자 작성; 개념 근거: [Orth, Thiele and Palsson (2010)](https://doi.org/10.1038/nbt.1614), [Michaelis and Menten (1913)](https://doi.org/10.1042/bj0070310).

## 생성 후 필수 검수 결과

1. 각 JSON을 `gen_one.py`에 한 개씩 입력해 2K 결과를 생성했다.
2. 원본 해상도 과학 검수에서 분기 관계, 화살표 방향, 군집 물질수지와 진단 흐름을 확인했다.
3. 한글을 음절 단위로 읽어 오타·깨짐·환각 텍스트가 없는지 확인했다.
4. 각 패널과 핵심 라벨이 spec에서 빠지지 않았고 gradient·shadow·잘림·겹침이 없음을 확인했다.
5. PASS 결과만 게시하고 본문 링크, 최종 캡션, 기존 Mermaid 번호를 함께 갱신했다.
