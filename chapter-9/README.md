# Chapter 9. 머신러닝으로 유전자 필수성을 읽는다

> [Chapter 4](../chapter-4/README.md)는 배지와 목적함수를 정한 뒤 유전자 교란을 계산하고, [유전자 결손](../chapter-4/05.md)·[MOMA](../chapter-4/11.md)·[ROOM](../chapter-4/12.md)의 질문을 구분했다. 이 장은 그 계산 결과와 실험 자료를 머신러닝의 입력·레이블로 정리하고, 유전자 필수성 분류 결과를 과장 없이 평가하는 입문 절차를 다룬다.

## 표기와 읽기 원칙

이 장에서는 서로 다른 두 종류의 모델을 구분한다.

- **게놈 규모 대사 모델**(Genome-scale Metabolic Model, GEM)은 반응·대사물·GPR·경계조건과 목적함수로 조건부 계산 문제를 정의한다.
- **머신러닝 모델**(Machine Learning model, ML model)은 특징과 레이블의 관계를 자료에서 학습한다.
- **계산 레이블**은 특정 GEM·배지·목적함수·결손 규칙으로 만든 결과다.
- **실험 레이블**은 특정 생물종 또는 세포주·배지·측정법·시간·판정 임계값에서 얻은 관찰 결과다.

처음 등장하는 용어는 한국어와 영어 원어를 함께 표기하며, 이후에는 한국어 또는 약어 한 가지를 일관되게 사용한다. 분류 성능은 정확도 하나가 아니라 정밀도·재현율·매튜 상관계수와 함께 읽는다.

{% hint style="warning" %}
본문의 “예측”은 명시된 자료와 분할 규칙 아래의 통계적 출력이다. 계산 레이블을 잘 재현했다고 해서 실험적 유전자 필수성을 검증한 것은 아니며, 실험 레이블도 조건이 바뀌면 달라질 수 있다.
{% endhint %}

## 이 장을 시작하며

유전자 하나를 제거했을 때 성장이 유지되는지는 GEM으로 계산할 수도 있고 실험으로 관찰할 수도 있다. 두 결과는 같은 질문을 겨냥하지만 서로 다른 절차에서 만들어진다. GEM 계산은 화학량론·GPR·배지·목적함수에 의존하고, 실험 관찰은 생물학적 배경·배양 조건·측정 잡음과 판정 기준에 의존한다.

머신러닝은 여러 특징을 이용해 필수·비필수 범주를 구분하는 데 도움을 줄 수 있다. 그러나 입력과 레이블이 같은 계산에서 파생되었거나, 같은 세포주의 자료가 훈련과 테스트에 함께 들어가면 성능이 실제보다 높아질 수 있다. 이 장의 중심 질문은 “어떤 알고리듬이 가장 복잡한가”가 아니라 “무엇을 레이블로 삼았고, 어떤 단위로 자료를 나누었으며, 어떤 지표로 검증했는가”이다.

|:---:|:---|:---|
| [§1](01.md) | GEM·ML·실험의 역할 구분 | 각 단계가 만드는 결과와 한계는 무엇인가 |
| [§2](02.md) | 분류, 자료 분할, 교차검증, 누출, 불균형, 평가지표 | 보고된 성능이 새로운 생물학적 조건을 시험했는가 |

선형대수나 최적화 과목을 이수하지 않아도 읽을 수 있도록, 알고리듬 내부의 복잡한 계산은 다루지 않는다. 필요한 계산은 혼동 행렬의 네 칸과 간단한 비율에 한정한다.

## 학습 목표

이 장을 마치면 다음을 할 수 있다.

- GEM, 머신러닝과 실험 검증의 역할을 구분한다.
- 분류의 특징·레이블·예측 범주를 유전자 필수성 사례로 정의한다.
- 훈련·검증·테스트 자료의 역할과 교차검증의 목적을 설명한다.
- 세포주·생물종·배양 조건 단위의 자료 누출을 식별한다.
- 혼동 행렬에서 정밀도·재현율·정확도·매튜 상관계수를 계산하고 클래스 불균형의 영향을 해석한다.
- 계산 레이블과 실험 레이블의 생성 조건을 기록하고, 두 레이블의 불일치를 생물학적 검토 대상으로 평가한다.
