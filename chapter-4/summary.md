# 마무리: 요약 · 스스로 점검 · 용어

## 한 장 요약

- FBA 분석은 생물학적 질문을 배지, 반응 경계와 목적함수로 번역하는 데서 시작한다.
- 교환 반응은 모델과 환경을 연결하며, 흔한 COBRA 부호 규약에서는 음의 교환 플럭스가 섭취를 뜻한다. 반응식과 경계를 함께 확인해야 한다.
- FBA의 최소 수식은 물질수지 $$\mathbf{S}\mathbf{v}=\mathbf{0}$$, 반응 경계와 목적함수다. 의사정상상태는 내부 대사물이 순축적되지 않는다는 근사이지 모든 플럭스가 0이라는 뜻이 아니다.
- `optimal`은 수치 허용오차 안에서 최적해를 찾았다는 솔버 상태다. 생물학적 가설이나 실험 표현형이 검증되었다는 뜻은 아니다.
- 유전자 결손은 GPR의 `and`·`or`를 평가한 뒤 기능을 잃은 반응의 경계를 0으로 바꾸어 적용한다. 반응 결손, 예측 성장 결손과 실험적 필수성은 서로 다른 판정이다.
- 필수성은 모델, 배지, 목적함수와 임계값에 의존한다. 최소 배지에서 필수인 생합성 유전자가 해당 영양소를 공급한 배지에서는 비필수로 바뀔 수 있다.
- pFBA는 주 목적값을 유지하며 전체 절대 플럭스가 작은 대표 해를 고른다. 효소 질량 최소화나 해의 유일성을 보장하지 않는다.
- FVA는 지정한 목적 수준 아래에서 반응별 최소·최대 플럭스를 계산한다. FVA 구간은 공동 플럭스 벡터나 통계적 신뢰구간이 아니다.
- FBA는 교란된 세포가 목적을 다시 최적화한다고 가정한다. MOMA는 WT 기준 플럭스와의 거리를 줄이고, ROOM은 WT 허용 범위를 크게 벗어나는 반응 수를 줄인다.
- MOMA와 ROOM의 목적값은 성장률이 아니다. 세 방법의 성장률은 모두 바이오매스 반응 플럭스에서 읽어야 한다.
- 방법 선택은 보편적 시간표가 아니라 비교할 상태 가설, WT 기준 플럭스, ROOM 임계값과 실험 endpoint에 따라 결정한다.
- 모델·배지·목적함수·결손·솔버·허용오차·구현 변형을 함께 기록해야 계산을 재현하고 결과 차이의 원인을 추적할 수 있다.

## 분석 흐름

_표 S.1:_ Chapter 4의 입력, 질문과 출력을 연결한 분석 흐름이다.

| 단계 | 입력 | 핵심 질문 | 출력 |
|:---|:---|:---|:---|
| 기준 설정 | 모델·배지·목적함수 | WT가 실행 가능하고 성장하는가 | 상태·성장률·교환 플럭스 |
| 조건 비교 | 한 번에 한 경계 변화 | 입력 변화가 어떤 출력을 바꾸는가 | 조건별 차이 |
| 유전자 결손 | GPR·결손 목록 | 어떤 반응이 꺼지고 성장이 유지되는가 | 결손 성장률·비율 |
| 비유일성 진단 | 최적 또는 준최적 기준 | 대표 해와 허용 범위는 무엇인가 | pFBA 해·FVA 구간 |
| 교란 상태 비교 | 결손 모델·WT 기준 | 재최적화·근접성·희소 변화 가설이 어떻게 다른가 | FBA·MOMA·ROOM 비교 |
| 실험 평가 | 일치한 배지·시점·endpoint | 어느 가설이 관측과 일치하는가 | 검증 범위·큐레이션 과제 |

## 스스로 점검

1. **정의 확인:** FBA의 세 입력을 쓰고, 각 입력이 생물학적 사실인지 분석 설정인지 구분하라.
   > **힌트:** 물질수지, 반응 경계와 목적함수의 근거가 서로 어떻게 다른지 비교한다.

2. **손 계산:** `R: g1 or g2`와 `Q: g3 and g4`가 있다. `g1` 단일 결손과 `g3` 단일 결손에서 각 반응이 유지되는지 판정하라.
   > **힌트:** 결손 유전자를 `False`, 나머지를 `True`로 치환해 식 전체를 평가한다.

3. **결과 해석:** FVA 결과가 `R1=[0,0]`, `R2=[-5,-2]`, `R3=[-4,6]`이다. 현재 목적 수준에서 각 반응을 분류하고, 이 정보만으로 단일 유전자 필수성을 판정할 수 있는지 설명하라.
   > **힌트:** 차단, 목표 유지에 필요함과 유연함을 구분한 뒤 GPR의 역할을 고려한다.

4. **가정 비교:** 같은 결손에서 FBA 성장률은 0.7, linear MOMA의 `objective_value`는 250, 바이오매스 플럭스는 0.2라고 하자. “MOMA 성장률은 250이다”라는 해석의 오류를 설명하라.
   > **힌트:** 방법 목적값과 바이오매스 반응 플럭스가 답하는 질문을 구분한다.

5. **조건 설계:** 산소 차단의 효과를 분석하면서 포도당 상한과 목적함수도 함께 바꾸었다. 이 비교의 문제를 지적하고 더 나은 대조 실험을 설계하라.
   > **힌트:** 한 번에 한 조건만 바꾸는 원칙을 적용한다.

6. **가정 비판:** 결손 직후 측정한 플럭스와 적응진화 뒤 성장률 자료가 모두 있다. FBA·MOMA·ROOM을 어떤 순서로 비교하고 어떤 결론을 피해야 하는지 서술하라.
   > **힌트:** 방법을 고정된 시간표로 배정하지 말고 각 시점의 관측 endpoint와 상태 선택 가설을 연결한다.

## 핵심 용어

| 용어 | English | 정의 |
|:---|:---|:---|
| [플럭스 균형 분석](../glossary.md) | Flux Balance Analysis | 물질수지와 반응 경계 아래 지정한 목적을 최적화하는 방법 |
| 의사정상상태 | Pseudo-steady state | 관심 시간 척도에서 내부 대사물의 순축적을 0으로 근사한 상태 |
| 교환 반응 | Exchange reaction | 모델과 세포외 환경 사이 물질 이동을 나타내는 반응 |
| 경계조건 | Flux bounds | 반응이 허용되는 방향과 범위 |
| 목적함수 | Objective function | 가능한 상태를 선택하는 계산 기준 |
| GPR | Gene-Protein-Reaction association | 유전자와 효소 기능, 반응의 관계를 나타내는 논리 규칙 |
| 조건 특이적 필수성 | Condition-dependent essentiality | 배지와 목적에 따라 달라지는 결손 성장 요구성 |
| [pFBA](../glossary.md) | Parsimonious FBA | 주 목적값을 유지하면서 전체 절대 플럭스가 작은 대표 해를 고르는 방법 |
| [FVA](../glossary.md) | Flux Variability Analysis | 목적 수준 아래 반응별 최소·최대 플럭스를 계산하는 방법 |
| MOMA | Minimization of Metabolic Adjustment | 돌연변이 제약에서 WT 기준 플럭스와의 거리를 최소화하는 방법 |
| ROOM | Regulatory On/Off Minimization | WT 허용 범위를 크게 벗어난 반응 수를 최소화하는 방법 |
| 기준 플럭스 | Reference flux | MOMA와 ROOM의 변화 기준으로 사용하는 WT 플럭스 |

## 답안

1. 물질수지는 모델 반응식과 의사정상상태 가정에서 오며, 경계는 배지·방향·용량을 표현하고, 목적함수는 상태 선택 기준이다. 세 항목 모두 모델링 선택을 포함하며 특히 경계와 목적함수는 명시적 분석 설정이다.
2. `g1` 결손에서 `R`은 `False or True=True`이므로 유지된다. `g3` 결손에서 `Q`는 `False and True=False`이므로 차단된다.
3. `R1`은 현재 조건에서 차단되고, `R2`는 0을 포함하지 않으므로 지정한 목적 수준 유지에 필요하며, `R3`은 0을 포함하고 폭이 넓어 유연하다. 반응 수준 정보만으로 단일 유전자 필수성을 판정할 수 없으며 GPR과 결손 후 재계산이 필요하다.
4. 250은 WT 기준과의 linear MOMA 거리 목적값이다. 성장률은 바이오매스 플럭스 0.2이며 FBA 성장률 0.7과 비교할 값도 0.2다.
5. 세 입력을 동시에 바꾸면 산소 효과를 분리할 수 없다. 포도당 상한과 목적함수를 기준 조건과 동일하게 유지하고 산소 섭취 경계만 0으로 바꾼다.
6. 결손 직후 플럭스에는 MOMA의 WT 근접성, ROOM의 소수 변화와 FBA의 재최적화 가설을 모두 비교한다. 적응 후 성장률에도 세 방법의 바이오매스 플럭스를 비교하되 FBA를 주요 후보로 포함한다. 특정 방법을 시간만으로 정답으로 배정하거나 한 데이터셋의 우열을 보편화하지 않는다.
