# 그림 캡션 작성 기준

캡션은 그림을 본문과 분리해 보아도 입력·조건·출력·해석 한계를 알 수 있도록 작성한다.

## 개념 모식도

다음 요소를 한 문단에 포함한다.

1. 그림이 비교하거나 연결하는 생물학적 대상
2. 색·화살표·패널이 뜻하는 관계
3. 실제 모델 계산이나 실험 관찰이 아니라는 범위
4. `저자 작성`과 개념 근거 문헌

## 계산 그림

다음 요소를 기록한다.

1. 모델 이름·릴리스 또는 파일
2. 배지·경계조건·목적함수
3. 계산법·주요 옵션·솔버
4. 축·단위·표시값의 의미
5. 통계적 신뢰구간이나 실험 관찰로 오해하지 않도록 하는 한계
6. 생성 스크립트와 데이터 원출처

## 외부 실물 사진

대상·촬영 조건을 설명하고 원저작자·기관·파일 페이지·라이선스를 표시한다. AI 생성 이미지로 실물 사진이나 실험 관찰을 대체하지 않는다.

## 금지 사항

- 이미지 안에 캡션·출처·워터마크 삽입
- 모델·배지·단위가 없는 정량 주장
- 모의값을 실측값처럼 표현
- 외부 논문 그림의 레이아웃을 복제하거나 트레이싱
- 검수하지 않은 생성 이미지의 본문 삽입
